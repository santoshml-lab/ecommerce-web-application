# 🛒 ShopFlow - E-Commerce Web Application

A full-stack e-commerce web application built to provide a simple and responsive online shopping experience.

## 🚀 Live Demo

- 🌐 Frontend (Netlify): https://fabulous-crepe-57a40f.netlify.app/
- ⚙️ Backend API (Render): https://ecommerce-web-application-1g0v.onrender.com/
- 💻 GitHub Repository: `https://github.com/santoshml-lab/ecommerce-web-application

## ✨ Features

- 🔐 User Signup & Login
- 🛍️ Product Catalog
- 🛒 Add to Cart
- ➕➖ Cart Quantity Management
- 💰 Automatic Cart Total
- 📦 Checkout & Order Creation
- 📋 Order Tracking
- 📊 Stock Management
- 📱 Responsive Design
- 🔗 Frontend–Backend API Integration
- 🗄️ Supabase Database Integration
